# مرن | دائرة الطرق بمحافظة البريمي

نموذج أولي (Prototype / MVP Demo) باللغة العربية، مصمم للعمل محلياً دون أي خدمات أو مكتبات خارجية، ويمكن عرضه على GitHub Pages.

## الوظائف الحالية

- لوحة رئيسية ومؤشرات تحسب تلقائياً من البيانات المعروضة.
- إدارة المهام: إضافة وإسناد المهام، التصفية، البحث، تغيير حالة الإنجاز.
- جدول العمل المرن أسبوعياً وتوزيع الفريق بحسب المكتب / عن بُعد / ميداني.
- إنشاء طلبات العمل المرن ومحاكاة اعتمادها أو رفضها.
- سجل افتراضي للموظفين والأقسام.
- تقارير ومؤشرات، تصدير CSV، والطباعة.
- 3 حسابات عرض تجريبية: مدير الدائرة، رئيس القسم، موظف.
- واجهة متجاوبة للشاشات المكتبية والهواتف.
- حفظ التغييرات في متصفح المستخدم عبر localStorage.

## التشغيل

1. افتح `index.html` في متصفح حديث، أو ارفع كل الملفات مع الحفاظ على بنيتها إلى مستودع GitHub.
2. من GitHub Settings > Pages، اختر Deploy from a branch ثم main و /(root)، إن كانت صفحة المستودع مهيأة للنشر بتلك الطريقة.
3. افتح رابط GitHub Pages. الملفات محلية بالكامل ولا تحتاج مفتاح API أو CDN.
4. التبديل بين حسابات العرض يتم عبر القائمة العلوية لتجربة صلاحيات الواجهة.
5. اختبر: إضافة مهمة كمدير > تغيير الحساب إلى موظف > تحديث حالة المهمة (إذا أسندت إليه). اطلب عملاً مرناً كموظف > عد للمدير > اعتمد أو ارفض.

## تحذيرات مهمة قبل الاستخدام المؤسسي

**هذا النظام ليس منصة إنتاجية حكومية معتمدة**: لا توجد مصادقة فعلية، ولا قاعدة بيانات مشتركة، ولا صلاحيات مضمونة من خادم. محاكاة الصلاحيات في الواجهة قابلة للتجاوز. جميع الموظفين والأرقام والمهام افتراضية. بيانات localStorage منفصلة على كل جهاز/متصفح ويمكن حذفها؛ لا يوجد نسخ احتياطي أو مزامنة بين الأجهزة.

**لا تدخل أي بيانات موظفين حقيقية أو معلومات رسمية أو شخصية أو حساسة في هذه النسخة.**

قبل النشر للعمل الفعلي يجب اعتماد بنية متوافقة مع اشتراطات الوزارة وأمن المعلومات، تشمل على الأقل:

1. تسجيل دخول عبر الهوية/الدليل الحكومي المعتمد، دون حسابات عرض أو تبديل صلاحيات.
2. قاعدة بيانات وخادم مع فرض صلاحيات RBAC على الخادم، وقواعد فصل الأقسام واعتماد الطلبات ومنع اعتماد الطلب ذاتياً.
3. ضوابط سرية البيانات، تدقيق العمليات، أرشفة القرارات، النسخ الاحتياطي والتعافي، وموافقة الجهة المالكة للبيانات.
4. سياسة عمل مرن مصدّق عليها، تشمل تأهيل المهام الميدانية، الساعات الرسمية، معالجة التعارض والتظلمات.
5. اختبار إتاحة WCAG 2.2 AA، اختبار اختراق، مراجعة خصوصية، وتجربة مستخدم مع موظفي الدائرة.
6. إكمال ترابط المهام بمؤشرات الجودة وخدمات المستفيدين، وتجنب اتخاذ قرارات وظيفية من مجرد عدد المهام المنجزة.

## ملفات المشروع

- `index.html`: الصفحة الأساسية.
- `styles.css`: الأنماط العربية RTL والاستجابة.
- `app.js`: منطق التطبيق والبيانات الافتراضية.
- `assets/icon.svg`: أيقونة التطبيق.
- `manifest.webmanifest`: بيانات إضافة التطبيق إلى الشاشة الرئيسية.
